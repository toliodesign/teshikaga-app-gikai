# 弟子屈町議会 動画目次（非公式）

弟子屈町議会の公式YouTubeチャンネルの動画を、会議ごと・年ごと・議員ごと・キーワードで探せる目次サイトです。
新しい動画は、毎日朝6時ごろに自動で取り込みます。

## 中身
- `index.html` … サイトの画面の骨組み
- `style.css` … 見た目
- `app.js` … 検索や並べ替えなどの動き
- `icons.js` … アイコン（Font Awesome Free 7.3.1 から、使う13個だけを取り出したもの）。ライセンスはCC BY 4.0で、ページ下部に作者名とライセンスを表示しています（表示を消さないでください）。アイコンを足すときは、`ICONS` に同じ形で足し、`index.html` や `app.js` で `ic("名前")` を使います。
- `vercel.json` … 安全のための設定（Vercelが公開するときに、ブラウザへ送る決まり）
- `icon-32.png` `icon-192.png` `icon-512.png` `icon-maskable-512.png` `apple-touch-icon.png` `manifest.webmanifest` … アプリ用のアイコンと設定。ブラウザのタブ、スマホのホーム画面、Androidの「アプリとして追加」で使います。元の絵は、512×512の1枚（茶色の地に議場と再生マーク）です。`apple-touch-icon.png` は、iPhoneが角を自分で丸めるため、角まで茶色で塗ってあります。`icon-maskable-512.png` は、端末の形（丸など）で切り取られても絵が欠けないよう、絵を小さめに置いてあります。
- `data/videos.json` … 動画の一覧データ（今は試し用の4本。自動更新で全動画に置き換わります）
- `data/members.json` … 議員の一覧（名字・フルネーム・よみ・写真のアドレス・町の議員名簿ページ）。議員別のあいうえお順と、一般質問に出す写真つきのリンクに使います。議員が代わったら、同じ形で書き換えてください。`photo` を空にすると、写真は出ず名前のリンクだけになります。よみは、町のページに書かれていないため、写真ファイル名のローマ字から付けた推測です。確認してください。
- `data/kinds.json` … 動画の「種類」（一般質問、予算特別委員会など）を決めるきまりです。上から順に、タイトルに言葉が入っていた最初の種類になります。新しい種類が出たら、`rules` に1行足すだけで、サイトに種類のボタンが増えます（例：`{"name":"決算特別委員会","title":["決算特別委員"]}`）。どれにも合わない動画は「その他」に入り、毎朝の自動実行の記録に、青い知らせとして一覧が出ます。
- `scripts/update.py` … YouTubeから動画情報を集めて `videos.json` を作るプログラム
- `.github/workflows/update.yml` … 毎日の自動実行の設定

## 自動更新が動いているかの確かめ方
- 毎日の確認の結果は、`data/status.json` に保存されます（1日に1回、または動画が変わったとき）。サイトの上のほうに、「最終更新：（動画データが変わった日時）　最終確認：（毎日の確認の日付）」と出ます。**動画が増えない日でも、「最終確認」の日付は進みます。**
- GitHubの「Actions」→ 実行をクリックすると、画面の下の「Summary」に、確認日時、取り込んだ動画の本数、YouTubeのチャンネルの動画数、最新の動画3本が、文章で出ます。
- YouTubeの動画数と、取り込んだ本数が違うときは、黄色い注意が出ます（公開の設定や、取得の遅れが原因かもしれません）。
- 自動実行は、毎日の朝6時（日本時間）に予定されていますが、GitHubの都合で、数時間遅れることがあります。

## 議員が代わったとき（選挙のあと）
`data/members.json` を、次のように書き換えます。**退任した議員の行は、消さないでください。** 消さなければ、過去の動画の表示（名前・写真）が、そのまま残ります。
1. **退任した議員**：行は残し、任期の終わりの日付を足します。例：`"until": "2028-12-31"`。この日を過ぎると、「前議員」と表示されます。
2. **新しい議員**：新しい行を足します。任期の始まりの日付を、`"since": "2029-01-01"` のように書きます。
3. **同じ名字の人が複数いるとき**：名字の下を、`[ { ... }, { ... } ]` のように並べて書きます。会議の日にちから、どちらの人かが、自動で決まります。そのとき、画面の見出しなどは、フルネームで区別されます。
4. 町のサイトから、写真が消えたときも、名前の表示は続きます（写真だけ出なくなります）。

```
"高橋": [
  { "full": "高橋正秀", "yomi": "たかはし", "photo": "…", "page": "…", "until": "2028-12-31" },
  { "full": "高橋新",   "yomi": "たかはし", "photo": "…", "page": "…", "since": "2029-01-01" }
]
```
※ 日付は、「年-月-日」（半角）で書きます。任期の日付がない議員は、ずっと現職として扱います。

## 公開までの手順（GitHub）
1. GitHubで新しいリポジトリを作る（名前の例：`teshikaga-gikai-mokuji`、公開設定は Public）。
2. このフォルダの中身を、すべてリポジトリに入れる。
   `.github` フォルダが入らないときは、GitHubの「Add file → Create new file」で `.github/workflows/update.yml` と入力し、別添の `update.yml` の中身を貼り付ける。
3. YouTubeのAPIキーを作る（無料）。
   Google Cloud Consoleでプロジェクトを作り、「YouTube Data API v3」を有効にして、「認証情報」からAPIキーを作成する。
4. リポジトリの Settings → Secrets and variables → Actions で、`YOUTUBE_API_KEY` という名前でAPIキーを登録する。
5. Settings → Pages で、公開元を「Deploy from a branch」、ブランチを `main`（フォルダは `/ (root)`）にする。
6. 「Actions」タブ → 「動画一覧を更新」→「Run workflow」で、最初の取り込みを実行する。
7. サイトを開き、動画が42本（またはその時点の本数）出ているか確認する。

※ GitHubの画面の言葉や並びは、変わっている場合があります。

## うまくいかないとき
- **動画が4本のまま**: Actionsタブで実行結果を見る。「YOUTUBE_API_KEY が設定されていません」と出ていれば、手順4をやり直す。
- **自動実行が止まった**: 長く操作がないと、GitHubが自動実行を止めることがあります（私の知る限りです）。Actionsタブから再び有効にしてください。
- **更新したのにサイトに反映されない**: 反映まで数分かかります。それでも変わらないときは、Settings → Pages の設定を確認してください。

## 読み取りのきまり
- 動画のタイトルから、会議名・日目・会議日・種類・議員名を読み取ります。「一般質問（○○議員）」の形のときだけ、議員別に出ます。
- 説明欄の「********」より上だけを使います（下は全動画共通の注意書きです）。
- 読み取れないものは、推測せず「未分類」「不明」のまま表示します。
- 議員名はタイトルの名字のままです。同じ名字の議員がいると、同じ見出しにまとまります。
- 「年別」は、会議名の「令和○年」で分けています（4月〜3月の年度ではありません）。
- 動画の転載はせず、YouTubeへのリンクだけを並べます。

## 安全のための設計（2026年10月の見直しで追加）
- **画面**: 動画の情報（題名、時刻、動画ID、写真のアドレスなど）は、外から来るものとして扱います。動画IDと時刻は決まった形のものだけを使い、写真は弟子屈町のサイトのものだけを出します。形がおかしい動画は、表示から外します。
- **ブラウザの安全設定（vercel.json）**: 自分のファイル以外のプログラムを動かさない決まり（CSP）を付けています。許しているのは、このサイト自身のファイル、Googleのフォント、弟子屈町の写真だけです。
- **公開した直後の確認**: サイトを開き、キーボードのF12（またはブラウザのメニューの「開発者ツール」）→「Console」を見てください。「Refused to ...」という赤い文が出ていたら、安全設定が何かをふさいでいます。画面が正しく動いていて、赤い文が出ていなければ問題ありません。うまく動かないときは、`vercel.json` を一時的に消せば、元の動きに戻ります。
- **更新プログラム**: APIキーは、動画を集める作業だけに渡します。通信が失敗しても、キーを記録に出しません。動画の数が前回の半分より少なくなったときは、取得の失敗かもしれないので、更新を止めます（本当に減ったときは、`FORCE_UPDATE=1` をつけて実行します）。
- **自動実行の権限**: 全体は「読むだけ」で、書き込みの権限は、更新の作業だけに与えています。同時に2つ動かさず、10分で止まります。
- **残る注意**: GitHub Actionsの部品（checkoutなど）は、「v4」のような名前で指定しています。さらに安全にするには、版の固定（コミットの長い番号）にしますが、番号は、公式の画面で確認してから入れてください。Googleフォントを使っているので、サイトを開いた人の接続情報はGoogleにも送られます。気になる場合は、フォントを自分のサイトに置く方法もあります。
